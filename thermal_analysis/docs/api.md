## thermal_analysis.pipeline

Complete analysis of one thermal impedance curve.

One function, ``analyse``, runs the whole chain used by the window and by
the command line, so both give the same Foster network:

    derivative -> choice of M -> scan of tau -> joint least squares
    -> Cauer network -> structure functions

The two front ends only differ in how they compute the structure functions,
chosen with ``structure``:

* ``"pyrth"`` (window): PyRth on a Foster curve rebuilt on 500 points;
* ``"cauer"`` (command line): cumulative sums of the Cauer network.

Every setting comes from ``thermal_analysis.config``.


## thermal_analysis.ltspice

LTspice model of the identified network.

Writes, for one thermal impedance curve, a model, a symbol and a test bench
for each of the two networks, as kicad_icepak (v47) does for the coupled
model of a board:

    <BASE>_FOSTER.net             subcircuit <BASE>_FOSTER (Foster network)
    <BASE>_FOSTER.asy             LTspice symbol of <BASE>_FOSTER
    <BASE>_FOSTER_testbench.net   power step on <BASE>_FOSTER
    <BASE>_CAUER.net              subcircuit <BASE>_CAUER (Cauer network)
    <BASE>_CAUER.asy              LTspice symbol of <BASE>_CAUER
    <BASE>_CAUER_testbench.net    power step on <BASE>_CAUER

Electrical analogy: 1 A = 1 W, 1 V = 1 degC (or 1 K of rise), 1 Ohm = 1 K/W,
1 F = 1 J/K.

Each subcircuit has the pins of the v47 model, ``P T TAMB``:

* ``P``: power input. The current that enters ``P`` is the dissipated power.
  A 0 V source to ``TAMB`` measures it.
* a current-controlled current source (``F``) copies that current into the
  RC network, whose inner nodes connect to nothing outside the subcircuit;
* ``T``: temperature output, ``V(T) = V(TAMB) + Zth * P``, given by a
  voltage-controlled voltage source (``E``), so a load on ``T`` doesn't
  change the network.

The files only contain ASCII characters, so that every LTspice version reads
them.

## thermal_analysis.cli

Command line of the thermal impedance analysis.

    python -m thermal_analysis.cli -file input.xlsx -nfb 10    (-nfb is optional)

Same options and outputs as cli_main.py of the stand-alone Zth_to_Foster
tool: foster.txt, cauer.txt, cumul.txt, diff.txt and five *_plot.txt
scripts, written in the current folder. With config.CLI_WRITE_LTSPICE (the
default), also the LTspice models of the network: for the Foster and the
Cauer network, a model <NAME>_<KIND>.net, a symbol <NAME>_<KIND>.asy and a
test bench <NAME>_<KIND>_testbench.net, where <NAME> comes from the name of
the input file. With config.EXCEL_EXPORT (the default), also the Excel
workbook <NAME>_results.xlsx.

### differential_structure_function

```python

```

